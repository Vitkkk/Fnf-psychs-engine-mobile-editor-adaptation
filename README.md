# FNF Psych Engine Mobile Editor Adaptation

Mobile-first creator tooling for the Kviks Psych Engine Android port.

Base source: `kviks/Psych-Engine-Android` pinned to commit `8d84350fa92ecdf2b359492e01524385df094851`.

Milestone 1 is intentionally limited to:
- Week Editor Mobile
- Chart Editor Mobile
- Event Editor Mobile

Gameplay behavior should remain unchanged unless editor integration strictly requires a compatibility fix.
